# Project 1 升级实验协议（结果产生前固定）

目标：完成课件基础项及有验证证据的扩展，并研究扣费后超过同期中国 CPI 的股票多头策略。年化 5%-8%、最大回撤 20% 是研究目标，不是预先保证的结果。

## 数据与时间分割

沿用 2019-12-31 选定的 1,000 只主板股票，保持原快照不变。追加历史每日估值/市值、财务公告、申万行业进出区间、沪深 300 价格指数和 CPI 月环比。

- 特征预热：2019-10 起；训练：2020-2022；选择/验证：2023-2024；最终评估：2025-01 至 2026-09-18。
- 原始动量的全区间结果已经被观察过，最终评估期并非完全未知的盲测。后续模型和组合选择不使用该期结果，报告披露这一限制。
- 回归标签为次日开盘买入、20 个交易日后开盘退出的收益；训练标签退出日期必须早于验证开始，清除跨分割边界标签。
- 每日横截面处理只用当日因子、市值及当时有效的行业区间。财报严格在公告日后的交易日才可用；记录历史修订及行业分类回溯的局限。
- CPI 只作事后购买力比较，按月环比连乘；比较截至共同完整月份，不能把同比连乘。股票基准注明为价格指数，不冒充含分红总收益。

## 候选与控制变量

候选规模事前限定：固定经济方向的多因子组合、Ridge、LightGBM、小型 MLP。每种模型一组固定参数，不在最终评估段调参。神经网络不是必须胜出的模型。

因子覆盖动量、反转、波动、振幅、量价、换手、价值、股息和盈利质量。给出完整因子卡。比较去极值/标准化前后及行业-市值中性化前后；用按日期横截面处理，避免全样本拟合。

组合默认每 20 个交易日调仓、50 个目标持仓；加入持仓缓冲、单股/行业权重上限、波动率目标和市场趋势仓位。所有信号和风控信息在下一开盘前已可得，允许现金、禁止杠杆和卖空。风险目标 12% 年化波动、最大股票敞口 90%；趋势窗口 120 日。成交费用沿用买 10 bp / 卖 15 bp，额外做成本敏感性。

验证段主选择规则：优先选择回撤 <=20%、净收益为正的候选，按年化收益/最大回撤比较；不满足时如实报告，再按同一风险收益比记录最佳候选。最终评估只用于报告达标与否，不能据此替换验证段选出的模型。

## 证据与交付

1. 原始亏损复核：年份、费用、集中度、缺失估值及典型成交；零费用策略单独重跑，与“同成交路径毛归因”区分。
2. 因子诊断：覆盖、分布、有效人数、IC/Rank IC、分组与缺失统计。
3. 模型对照：统一数据/标签/费用/组合；保留全部候选及随机种子。
4. 风控对照：同一分数比较基本组合与风险控制，并报告现金比例和换手。
5. 数据增量：分段拼接等于全量、重复导入不增加行；行业/市值中性化残差检查；滞后与未来扰动检查；独立账本核对。
6. 最终 6-10 页研究报告、20 分钟 Beamer 演示稿与讲稿、可运行平台、复现命令、脱敏提交包。用户授权代码与可公开材料推送原 GitHub 仓库。
