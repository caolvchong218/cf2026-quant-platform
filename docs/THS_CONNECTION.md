v2.5曾把股票价格追加至2026-10-20（新增16个交易日、15,295行），财务及行业参考仍冻结在2026-09-18。v2.6保留原快照，另行追加行情、每日特征以及财务／行业观测版本；财务由披露事件和月度扫描维护，行业每周检查。首次看到的修订只影响后续可用版本，不倒填历史特征。原1000股固定池仍保留，因此这些股票版本**不是原历史策略在所有数据口径上的等价延伸**。RSRS 的指数信号与 ETF 交易也有跟踪误差、分红、费用和整手差异。账户已创建、分数已准备、执行已启用、委托已受理、成交已核验是不同状态，页面分别显示。

1. 用“刷新当前账户／刷新全部账户”查询资金、持仓和当日成交。刷新只读，不开户、不提交订单。
2. 检查最新行情、信号日期、账户查询时间及各策略状态。旧信号、缺失数据、待核对委托不会自动跳过。
3. 在本机工作进程已启动的前提下，使用“允许后续自动模拟委托”开关。**UI 开关只修改执行设置，不会自动启动后台进程。**平台启动器会读取之前保存的开关：已允许时自动启动隐藏工作进程，独占锁阻止重复实例。“开关允许”与“服务在线”分别展示。
4. 交易日 **09:35–09:45（上海时间）**为执行窗口。后台在 **17:05后**以最新完整交易日为目标准备行情与信号；启动、晚间、次晨均可继续未完成任务。独立线程维护数据，主工作循环每30秒检查服务状态；成功日期以数据清单和服务记录为准。
5. 在“执行日志”确认委托结果；“已受理”不能当作已成交。出现结果未知时保留资金／持仓预约、停止相关后续委托，等待可核验回报，不自动重发。
6. “暂停后续自动委托”阻止后续发送，**不会撤销已经发出的订单**。当前官方协议没有已确认的撤单接口。

后台进程需要电脑开机、用户已登录、保持唤醒并能联网。关闭浏览器不一定停止进程；关机或休眠期间不会继续运行。可打开青序启动器恢复工作进程，也可按[安装步骤](CONTINUOUS_SIMULATION_V260.md)注册当前用户的登录、08:55、17:10及每分钟恢复触发器；支持错过时补启动，运行中忽略重复触发，不会自动开启执行开关。界面超过三分钟没有近期心跳时明确提示，不能把已保存的开关当作正在运行的证明。

本次前向观察的预设执行起点为 **2026-10-21**，实际开始时间以账户记录为准。V3 每20个官方交易日调仓；错过预定调仓日会保留当前持仓／现金，等待下一调仓日，不追补过去的订单。v2.6取消累计40日和仅2026年的准备限制：每批最多补20个交易日，完成分区后续跑；跨年按执行年度加载或训练对应模型。默认每笔股票委托不超过2万元、ETF不超过20万元，每账户每日买卖委托总额不超过40万元。

最终发送前再次检查本机开关、策略选择、实际执行时段及 30 秒内的同一原始报价；股票还检查当日涨跌停价格。网络请求结果未知时停止自动重试；确定未发送或被拒绝的同日意图也不会自行换价重送。已受理而没有可核验成交的委托会持续保留并阻止该账户新增计划，不能推定次日已撤销。跨日核验使用官方历史成交接口；实际非空成交的供应商字段仍待首笔成交验证。

在项目环境中手动启动后台工作循环：

```powershell
python scripts/run_simulation_service.py --root . --watch
```

`--refresh` 按已保存调度执行最多两轮有界准备，再进行一次正常服务检查；它遵守数据时点、退避和执行开关，在允许执行且处于交易窗口时仍可能发送委托。仅准备股票数据和分数可使用 `prepare_equity_forward.py`。`--watch` 每30秒循环，数据失败按1、5、15、60、180、360分钟退避；本轮已有持久进度则一分钟后继续，重启不会清空退避。手动运行需保留终端；平台启动器或计划任务启动的进程在后台运行，独占锁阻止重复工作实例。

本机 Tushare 凭据路径为 `D:/CodexData/private/qingxu/tushare_token.txt`，仅在本机读取。不要把密钥内容写进命令、截图、报告或仓库。自动服务配置位于 `runs/simulation_auto/settings.json`；新安装默认关闭执行。股票数据准备工具 `scripts/prepare_equity_forward.py` 只生成带日期的数据与分数，不发送委托。

## 前瞻收益的解释

账户总资产由服务返回的资金和持仓市值组成。页面从首次有效观察计算资产变化；若另有出入金，资产变化不能直接视为投资收益。各策略的比较仅使用共同存在的观察日期，从共同起点重新归一，不填补缺失日期。

日度记录保留上海时间 15:15 后的最后一次有效查询；首次观察可作为基线。年化 Sharpe 使用日收益、252 个交易日、默认零无风险利率，至少要求 20 个日度区间和完整的已核验交易日覆盖。观察期不足、缺日或波动无法计算时显示原因。期末净资产为零会如实显示总损失，不会从统计中删除。

## 历史文件桥的使用步骤

1. 打开“模拟交易连接 → 历史组合导出”，选择 V3 实验和历史持仓日期。
2. 下载历史权重 CSV、六位代码 TXT 与组合说明 JSON。代码清单可供人工添加到模拟环境的自选观察列表；未验证同花顺是否接受该文件一键导入。
3. 在官方模拟环境中完成需要的模拟操作。SuperMind 帮助中的“模拟交易交易明细”说明可按时间范围导出成交记录。若实际下载的是 Excel 文件，请先另存为 CSV，并把代码列设为文本。
4. 打开“模拟回执核对”，选择“上传模拟成交 CSV”。查看编码识别、字段映射、逐行错误与重复提示。
5. 修正所有错误后，下载规范化成交、证券金额对账和校验摘要；点击“保存已验证模拟回执”留存本地记录。

没有模拟账户文件时，可以使用界面中的三笔合成示例走完整流程。示例的证券名称、价格和成交均为人工构造，**不是同花顺账户交易，也不是 V3 策略收益**。

## 历史组合导出约定

导出字段：`as_of`、`code`、`exchange`、`asset`、`reference_weight`、`usage`。

- `as_of` 是持仓截面对应的历史日期。发布包附带 2026-09-18 的固定历史观察截面；有本地逐股账本时可选择其他日期。
- `reference_weight` 为当日收盘实际持仓占完整组合净值的比例，包含价格变化后的权重漂移；不等于策略本次调仓的目标权重，更不是今天的交易信号。
- 回测账本的 `units` 是复权单位，**不能直接作为同花顺的真实股数**。导出文件故意不含 `units`、委托数量或价格。
- 观察列表不是订单文件。自动执行另行检查当前数据时点、现金、整数股数、交易单位、费用预约和未完成委托，不消费这份历史观察清单生成今天的订单。

## CSV 字段与校验

官方展示的成交明细字段为：交易时间、证券代码、证券名称、操作、交易价格、交易数量、交易金额。[SuperMind 模拟交易明细](https://quant.10jqka.com.cn/view/help/10)

| 规范字段 | 常见中文列名 | 本地校验 |
|---|---|---|
| `timestamp` | 交易时间、成交时间；也支持单列日期或日期 + 时间 | 必须包含有效年月日，检查未来时间；只有日期时保留日期精度，不补造成交时分秒。 |
| `code` | 证券代码、股票代码、代码 | 以文本读取，保留六位前导零；可识别 SH/SZ/BJ 后缀，补零时给出提示。 |
| `name` | 证券名称、股票名称 | 可选；疑似表格公式的名称按纯文本导出。 |
| `side` | 操作、买卖方向、交易方向 | 仅接受明确买入或卖出；撤单、信用交易等不能混入。 |
| `price` | 交易价格、成交价格、成交均价 | 有限正数。 |
| `quantity` | 交易数量、成交数量、成交股数 | 正整数股，拒绝将复权小数单位当股数。 |
| `amount` | 交易金额、成交金额、成交额 | 有限正数，逐行比较价格 × 数量；默认绝对允差 0.05 元，可在 0–1 元间调整。 |
| `trade_id` | 成交编号、成交序号 | 可选，重复编号会提示。 |

支持 UTF-8、GB18030，以及带 BOM 的 UTF-16；支持常见逗号或制表符文本。单文件限制 10 MB / 50,000 行。若有多个含义相同的中文列，需保留明确列名；规范化列名优先，使本平台导出文件可重新导入。

错误不会被静默删除：整份文件保留全部行，错误修正前不允许保存“已验证回执”。关键成交字段或成交编号重复时也保留每一行，只标记并提示；对账金额包含这些行，是否为真实重复必须与模拟平台核对。

## 金额对账不是收益计算

按证券汇总买入数量、卖出数量、买入金额、卖出金额，以及：

\[
\text{未扣费净现金流}=\text{卖出成交金额}-\text{买入成交金额}.
\]

这不是盈利，净成交数量变化也不是期末持仓。仅有成交文件时缺少初始资金、初始持仓、未平仓市值、分红和完整费用，不能计算账户收益率。本模块不把模拟成交现金流与 V3 的历史回测收益混为一谈。

## 保存与复现

- 规范化回执保存在 `runs/paper_imports/<内容摘要前24位>.json`，路径由源文件 SHA-256 生成，不使用上传文件名。
- 保存采用同目录临时文件和原子替换；相同源文件重复保存会返回已有回执，避免反复写入。每个回执保留来源类型、原文件摘要、编码、字段映射、允差、全部规范化行和检查结果。
- `runs/` 已列入 Git 忽略规则，用户模拟账户回执不会自动进入公共仓库。公开 `evidence/connections/` 仅放连接状态、合成样例、本地验证结果与历史观察权重。
- 专用模拟账户、观察快照、执行设置和持久委托账本保存在本机 `runs/simulation_auto/`，其中 `orders.sqlite` 记录稳定决策编号及实际回报。提交前先持久记录委托，进程中断后也不会自动重复发送。不要为了“重试”删除或换掉账本。
- 文件桥测试：`python -m pytest tests/test_simulation_bridge.py -q`。
- 自动执行与监控测试：`python -m pytest tests/test_simulation_execution.py tests/test_ths_simulation.py tests/test_ui_simulation_auto.py -q`。离线合成测试验证代码行为，不能替代真实模拟服务的成交验收。

历史接入验收确认专用模拟开户和查询；v2.6初扫与新版验收状态单独记录。仍未验证手机账户互通、挂单查询、撤单或前瞻收益，也不承诺当日财报即时全覆盖。SuperMind 的用户环境仍是独立的可选路线；保留文件桥有助于接收它导出的成交材料，但不把文件校验视为该环境已连接。
