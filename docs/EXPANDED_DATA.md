## 固定方案

- 在 2019-12-31 当天，以成交额降序选择符合主板代码、收盘价至少 3 元、有成交的前 1000 只股票；并列按代码排序。
- 请求 2019-10-01 至 2026-09-18 的日线、复权因子和涨跌停价格，研究区间从 2020-01-02 开始。
- 2026-09-21 开盘前，通过 600000.SH 日线查询核实最新已返回的交易日为 2026-09-18。本次固定下载到该日，不混入盘中数据。
- 不用今天仍上市的股票名单倒推历史；包含此后退市或停止报价的原股票池成员。该股票池不包含 2020 年后新上市的股票，不等于全 A 股或沪深 300。
- 单日成交额选样仍有流动性和热点偏差，没有完整历史 ST 名单过滤。固定股票池只应在选取日之后回测。
- 总容量预算为 3 GiB。原始缓存达到预算 65% 后停止继续发起资产下载，为 CSV 等留出空间；完成时再次核验总容量。并发请求可能造成少量预留阈值超出。成功缓存不会因下载中断被删除。

## 下载与续拉

在项目根目录运行（Token 文件路径按自己机器修改）：

```powershell
.venv/Scripts/python.exe -m cfquant.cli --root data/private/mainboard1000_20260918 download --token-file D:/Desktop/tushare_token.txt --assets 1000 --start 20191001 --end 20260918 --selection-date 20191231 --study-start 20200102 --delay 0.4 --workers 4 --max-gib 3
```

四个网络线程共用同一个限速器，每两次请求启动间隔至少 0.4 秒（每分钟约 150 次）。此频率要求账号接口权限支持；低配账号请保持默认 1.3 秒。参考 [Tushare 频次文档](https://tushare.pro/document/1?doc_id=290)。没有购买或升级任何权限。

重复相同命令即可利用已成功缓存的请求续拉。日期或字段变更会产生不同缓存身份；为保留旧数据证据，更新到新日期时使用新的 `--root`，并在配置中指向新快照。一次快照最多十年，防止单股接口行数截断。当前未实现跨日期快照的增量拼接。

快照目录：`data/private/mainboard1000_20260918`。

- `data/raw`：接口响应和不含凭据的请求参数。
- `data/processed/market.csv`：平台标准行情。
- `data/processed/universe.csv`、`calendar.csv`：选股日股票池及交易日历。
- `data/processed/quality.json`、`manifest.json`：质量检查和文件 SHA-256。
- `data/processed/progress.json`：下载进度；只有 `status=complete` 才会出现在平台数据集列表。

## 使用

下载完成后刷新平台，在侧栏“数据集”选择扩展快照，再运行回测或因子诊断。1000 只股票首次载入和计算会比 60 只样本慢。切换数据集会清除界面中的上一组回测结果。

```powershell
.venv/Scripts/python.exe -m cfquant.cli run --config configs/expanded.yaml
```

扩展配置默认持有排名前 30 只，每 5 个交易日调仓。这个设置用于运行验证，不代表收益最优。旧报告及研究总览中的 60 只股票结果保留原始日期和身份，不会被误标成新股票池的收益。
