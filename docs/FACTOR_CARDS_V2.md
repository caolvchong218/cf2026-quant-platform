# 扩展因子卡（V2）

实现：`src/cfquant/features.py`。原有三个注册式基准因子仍保留。以下方向在结果产生前固定，高分优先；不因最终IC为负而翻转符号。

## 公共规则

先对齐完整交易日历，不将停牌压缩。原始NaN保留，不用未来价格或财报填充。每个形成日独立1%/99%截尾与样本z标准化，再可选历史行业/对数市值OLS残差标准化。组合要求至少10/12因子有效；学习模型把剩余标准化特征NaN填为0，未来标签NaN直接排除。

财报只在公告日后可用；同公告日同报告期的冲突副本剔除。行业按[in_date,out_date)重构，未知/冲突为UNKNOWN。厂商历史修订与分类回溯风险仍然存在。

## 中期动量 / momentum_60_20

- 假设：排除最近一个月的中期趋势。
- 公式：`C(t-20)/C(t-60)-1`。
- 字段：close。
- 窗口/可得条件：61日完整价格。
- 方向：公式结果越大，事前预期收益越高。
- 缺失：窗口或字段不足记NaN，执行公共规则。
- 主要失败情形：趋势突变、样本风格集中。

## 短期反转 / reversal_5

- 假设：短期超调后可能反弹。
- 公式：`-(C(t)/C(t-5)-1)`。
- 字段：close。
- 窗口/可得条件：6日完整价格。
- 方向：公式结果越大，事前预期收益越高。
- 缺失：窗口或字段不足记NaN，执行公共规则。
- 主要失败情形：基本面恶化导致持续下跌。

## 低波动 / low_volatility_20

- 假设：低风险股票的风险收益特征。
- 公式：`-std(r,20)`。
- 字段：close。
- 窗口/可得条件：20个完整日收益。
- 方向：公式结果越大，事前预期收益越高。
- 缺失：窗口或字段不足记NaN，执行公共规则。
- 主要失败情形：快速牛市落后，与行业相关。

## 低振幅 / range_20

- 假设：日内振幅及交易拥挤程度。
- 公式：`-mean((H-L)/C,20)`。
- 字段：high, low, close。
- 窗口/可得条件：20日完整振幅。
- 方向：公式结果越大，事前预期收益越高。
- 缺失：窗口或字段不足记NaN，执行公共规则。
- 主要失败情形：与低波动高度重叠。

## 均线趋势 / trend_20

- 假设：偏离均线的趋势延续。
- 公式：`C/mean(C,20)-1`。
- 字段：close。
- 窗口/可得条件：20日完整价格。
- 方向：公式结果越大，事前预期收益越高。
- 缺失：窗口或字段不足记NaN，执行公共规则。
- 主要失败情形：震荡反复，方向不稳定。

## 成交量变化 / volume_trend

- 假设：量能变化与价格发现。
- 公式：`log(mean(V,5)/mean(V,20))`。
- 字段：volume，单位股。
- 窗口/可得条件：5日和20日完整量。
- 方向：公式结果越大，事前预期收益越高。
- 缺失：窗口或字段不足记NaN，执行公共规则。
- 主要失败情形：事件放量不一定预示上涨。

## 流动性 / liquidity_20

- 假设：单位成交额价格冲击。
- 公式：`-mean(abs(r)/(rawC*V/1e6),20)`。
- 字段：raw_close, volume, close。
- 窗口/可得条件：20日完整收益/成交额。
- 方向：公式结果越大，事前预期收益越高。
- 缺失：窗口或字段不足记NaN，执行公共规则。
- 主要失败情形：市值与流动性偏差、单位敏感。

## 低换手 / turnover

- 假设：换手拥挤与交易成本。
- 公式：`-turnover_rate`。
- 字段：daily_basic.turnover_rate，百分数。
- 窗口/可得条件：形成日。
- 方向：公式结果越大，事前预期收益越高。
- 缺失：窗口或字段不足记NaN，执行公共规则。
- 主要失败情形：低换手也可能意味着关注不足。

## 盈利收益率 / earnings_yield

- 假设：价格相对盈利的便宜程度。
- 公式：`1/PE_TTM (PE>0)`。
- 字段：daily_basic.pe_ttm。
- 窗口/可得条件：形成日且PE>0。
- 方向：公式结果越大，事前预期收益越高。
- 缺失：窗口或字段不足记NaN，执行公共规则。
- 主要失败情形：亏损公司缺失，价值陷阱。

## 账面市值比 / book_yield

- 假设：价格相对净资产的便宜程度。
- 公式：`1/PB (PB>0)`。
- 字段：daily_basic.pb。
- 窗口/可得条件：形成日且PB>0。
- 方向：公式结果越大，事前预期收益越高。
- 缺失：窗口或字段不足记NaN，执行公共规则。
- 主要失败情形：账面资产价值并不稳定。

## 股息率 / dividend_yield

- 假设：现金分红相对价格。
- 公式：`dv_ttm/100`。
- 字段：daily_basic.dv_ttm，百分数。
- 窗口/可得条件：形成日。
- 方向：公式结果越大，事前预期收益越高。
- 缺失：窗口或字段不足记NaN，执行公共规则。
- 主要失败情形：历史分红不代表未来分红。

## 盈利质量 / quality_roe

- 假设：历史年度盈利能力。
- 公式：`latest announced annual ROE/100`。
- 字段：fina_indicator.roe, ann_date, end_date。
- 窗口/可得条件：已公告年度，报告期距形成日≤550日。
- 方向：公式结果越大，事前预期收益越高。
- 缺失：窗口或字段不足记NaN，执行公共规则。
- 主要失败情形：公告滞后、厂商财报修订。

## 标准输出与使用

`features.parquet`是日期×资产长表，原始列、z_列和n_列对应原始、标准化与中性化版本。调用方可将任一列转为date/asset/factor/value四列，或pivot为日期×资产面板供组合模块使用。
完整每日IC、RankIC、样本量、分布、形成/有效组人数与20日组收益在`evidence/research_v2/factors`。这些诊断是重叠标签统计，不是可执行多空净值。
