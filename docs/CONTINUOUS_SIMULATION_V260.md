# 持续模拟运行 · v2.6

v2.6让同花顺专用模拟观察能够持续补数据、更新参考信息并跨年运行。原1000股研究快照、V3历史结果和两篇Project 2复现结论保持原身份；新数据、特征、模型和账户记录保存在本机私有运行目录。

当前真实参考数据初扫进行中。[新版验收记录预定位置](../evidence/simulation_continuous/acceptance.json)待生成，本文说明实现行为与操作方式，不表示初扫、安装或全部验收已经完成。[v2.5历史验收](../evidence/simulation_auto/acceptance.json)仍是独立记录。

## 持续准备的数据

| 项目 | 更新与恢复方式 |
|---|---|
| 目标交易日 | 上海时间17:05后取官方日历中的最新完整交易日；此前取更早的已完成交易日。启动、晚间和晨间均可补齐，休市日不猜测新交易日。 |
| 官方日历 | 独立维护，至少每周检查一次；调度要求覆盖未来14个自然日，获取时尝试预取45日。供应商尚未公布的日期不会自行填成交易日。 |
| 股票行情与估值 | 每批最多补20个交易日，每日四张表完成校验后保存检查点。没有累计40日上限；中断后从缺失分区继续，原快照不改写。 |
| 财务参考 | 检查披露事件，并对固定1000股池每月扫描；结合`fina_indicator`与`income`两阶段结果，按公告日期和报告期归并参考版本。完整扫描表示计划查询已完成，不表示每家公司都有有效财务值。 |
| 行业参考 | 每周维护申万2021行业版本，分别取得`is_new=Y/N`成员信息，保留行业区间与观测身份。 |
| 每日特征 | 形成日特征一经保存即冻结。首次观测日期限制数据可用范围，随后发现的最新年报修正只形成新的前向版本，不倒填旧日特征。 |
| V3年度模型 | 以**执行日期所属年份**选择模型；12个因子的标准化及中性化表示共24输入，参数保持固定。训练快照及文本模型均校验SHA，已有合格缓存时不每日重训。 |
| CogAlpha | 保留seed-731的20个已选公式，使用持续追加的固定复权锚行情计算当日排名；不因新收益重新挑选公式。 |

V3的年度截止点是该年首个执行交易日之前的交易日。训练形成日期落在此前三年，标签为`open[t+21] / open[t+1] - 1`，标签退出日期必须**严格早于年度截止点**。新行情只让已经成熟的标签可用；缺失端点保持无标签。年末信号若在次年执行，就使用次年模型。

财务公告仍须早于特征形成日。次晨补准备昨天的信号时，可以完成维护检查，但昨天的特征只使用昨天已经可用的参考版本。新公告、厂商修订与查询额度均可能造成覆盖差异，不承诺当日财报即时全覆盖；固定1000股池也不自动纳入新上市股票。

RSRS前向指数序列统一使用Tushare、以2019年为固定起点。已知的旧版“历史预载加Tushare”混合来源会完整重新取得，并保留旧文件及迁移摘要，不把两种来源继续拼接。正式论文复现使用的历史材料保持原身份。

如果官方修订未来开市日期，使已准备分数的执行日或执行年份改变，服务会阻止旧分数下单，并重新准备同一信号日。仅延长无关的未来日历不会触发重训。

## 启动与查看

在已配置私有数据、Tushare凭据和专用模拟账户的项目目录中运行：

```powershell
python scripts/run_simulation_service.py --root . --watch
```

工作进程每30秒循环。数据准备在独立线程进行，不占住执行心跳和暂停检查；一次只运行一个数据任务。执行仍限于官方交易日09:35–09:45，并在实际发送前重新检查开关、账户、数据日期及最新原始报价。

只进行一轮有界维护和服务检查：

```powershell
python scripts/run_simulation_service.py --root . --refresh
```

该命令遵守调度退避及已完成记录；它也会进行正常执行检查，允许执行且处于交易窗口时可能提交模拟委托。只准备股票数据与分数、不提交委托时可运行：

```powershell
$signalDate = Get-Date -Format "yyyy-MM-dd"
python scripts/prepare_equity_forward.py --data-root . --asof $signalDate
```

未到当天17:05时，准备工具按已完成交易日处理。首次维护可能需要多批，返回“进行中”表示已有进度而未准备好全部分数；常驻工作进程会按调度继续。Tushare凭据默认从`D:/CodexData/private/qingxu/tushare_token.txt`读取，命令中只传路径。

页面“模拟交易连接”用于检查心跳、数据与信号日期、账户状态和执行日志。本地详细记录位于：

| 私有路径，相对`runs/simulation_auto/` | 内容 |
|---|---|
| `refresh_schedule.json`、`refresh_status.json` | 持久任务状态、退避、目标日期和最近结果 |
| `calendar_store/`、`equity_market_store/` | 官方日历及逐交易日行情检查点 |
| `reference_store/`、`feature_store/` | 财务／行业观测版本及冻结日特征 |
| `annual_models/` | 各年度训练快照、文本模型和校验元数据 |
| `equities/`、`signals/` | 带日期的股票分数与ETF信号 |
| `service_status.json`、`orders.sqlite`、`decisions/` | 执行心跳、持久委托账本和冻结决策 |

## Windows自动启动

安装器要求当前目录已有配置文件和Python环境，不创建账户，也不修改执行开关。在项目目录运行；若虚拟环境名为`.venv`，相应替换下面的`.venv-clean`：

```powershell
powershell -NoProfile -File scripts/install_simulation_autostart.ps1 `
  -Root . -Python ".\.venv-clean\Scripts\pythonw.exe"
Get-ScheduledTask -TaskName QingxuContinuousSimulation
Get-ScheduledTaskInfo -TaskName QingxuContinuousSimulation
```

安装器注册**当前用户登录、每天08:55及17:10**触发器，另加**每分钟一次、无到期日期**的启动检查，并立即启动工作进程。`IgnoreNew`使正在运行的任务忽略重复触发，工作进程另有独占锁。任务支持`StartWhenAvailable`补启动；重复安装只接受同一程序和参数，不覆盖同名的其他任务。

本机实际测试中，仅设置`RestartOnFailure`未能在180秒内恢复退出码为1的工作进程，因此不能把该设置当作已经验证的进程守护。每分钟触发用于恢复缺席的服务；原失败重启设置仍保留为附加措施。重复间隔不设`Duration`即持续有效，依据[微软任务计划文档](https://learn.microsoft.com/en-us/windows/win32/taskschd/taskschedulerschema-duration-repetitiontype-element)；实际恢复结果另见本版验收记录。

安装后，平台启动器优先交由与当前目录匹配的计划任务启动后台服务，避免另起未受计划任务管理的工作进程。

电脑仍须开机、用户已登录、保持唤醒并联网；此安装不配置自动唤醒或关机运行。页面暂停阻止后续发送，数据维护可继续。计划任务显示“运行中”后仍应核对青序心跳，不能只依据任务已注册判断服务正常。

## 故障与恢复

无持久进度的失败按1、5、15、60、180、360分钟退避，之后保持最高间隔；任务状态保存在磁盘，重启不会清空。完成了部分已校验数据或参考任务时，一分钟后继续，不因正常分批赶进度而累积长时间退避。

训练先写独立临时目录，文件和校验信息完整后才发布年度缓存；中断的临时目录保留供检查，下次可重新训练。已发布模型或数据校验不符会明确阻断，不静默覆盖。不要删除委托账本、冻结决策或已提交分区来强行重试。

已受理、部分成交或结果未知的委托须先核对，不能自动假定撤销或重发。暂停也不会撤销已有订单。V3以2026-10-21为预设执行起点，每20个官方交易日调仓；错过调仓日保留实际持仓／现金等待下次，不补发过去的订单。

前瞻结果仅来自接入后的实际模拟账户观察，尚无经过验证的前瞻收益结论。RSRS使用指数信号、ETF执行；跟踪、分红、交易费用和整手约束均可能造成与历史指数回测的差异。账户与收益解释见[同花顺连接说明](THS_CONNECTION.md)。

## 复核长时间漏更

已有原始私有快照时，可以离线重放超过40个真实历史交易日，故意在中途打断再恢复：

```powershell
python scripts/validate_continuous_market_replay.py --data-root .
```

该检查不调用行情接口、不提交委托，不改原快照。它比较原CSV导出精度下的价格及其他字段，并确认补齐后再次运行不重复请求。跨年度年度模型、标签成熟与官方日历修订另由合成回归测试覆盖，不把未来年份测试称作真实行情验证。
