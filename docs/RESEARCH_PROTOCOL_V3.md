# V3：以沪深300为目标的新一轮历史研究协议

记录时点：2026-09-22；开始新实验之前提交。用户将目标从超过CPI升级为扣费后超过同期沪深300。V2及其失败/成功对照保留，不能事后改写。

## 信息边界与目标

价格数据和原12因子沿用同一1,000股历史快照。2025-01-02至2026-09-18的V2模型结果已经被观察，因此本轮任何该区间的改善都属于开发后的历史复核，不是全新盲测，也不保证未来战胜指数。

主要口径是策略扣费后的累计收益，减去同期沪深300价格指数累计收益（百分点）；另报告相对财富增长、跟踪误差、信息比率、beta、最大回撤、现金、年度和半年区间。保留之前收盘至最后收盘的标准价格基准，同时检查首次开盘起算基准，避免开始时点影响结论。若可获得全收益指数，则附加更严格的含分红比较，不能把价格指数称为全收益指数。

最终复核区间固定2025-01-02至2026-09-18，不缩短或移动。初步风险目标最大回撤25%，无杠杆、无做空；不要求每天或每年都战胜指数。按买10bp/卖15bp收费，另做双倍费用及延后一个交易日信号的压力检查。

## 有限候选与训练

一次预先限定8个候选：4种信号×2种组合规则。全部候选保留，不能删除失败结果。后续若需要新轮研究，另写协议，披露累计尝试数量。

四种信号：

1. 经济主题组合：价值主题（盈利收益率、账面市值比、股息率标准化均值）占50%，年度ROE占25%，低波动/低振幅主题均值占25%；至少10个原因子有效，个别标准化缺失取0。
2. 年度滚动Ridge：12个行业/市值中性化因子，alpha=100。
3. 年度滚动LightGBM：12个标准化因子及12个中性化因子，250树、学习率0.03、15叶、最大深度5、最小叶500、L2=10、列采样0.8、种子20260921；沿用既有容量，无最终期参数扫描。
4. 固定融合：上述LightGBM当日横截面百分位50%、Ridge百分位25%、经济主题百分位25%。

每年首次交易日前一个交易日收盘形成新模型。只训练该形成日之前最近3年的观测，且20日标签退出日严格早于该形成日。整个随后年度使用当次模型，下一年度才更新。特征始终在交易前已可见，避免训练样本使用将来实现的标签。2023/24用于候选选择，2025/26为之后的复核。

两种组合：均为每20交易日调仓、50只目标股、20名缓冲、逆波动权重、单股目标4%、行业目标25%、最高总仓位95%。A为稳定股票仓位；B为20%波动预算，沪深300低于120日均线时预算乘0.75。目标权重受上限约束，剩余现金按0利息；实际权重会随行情漂移。沿用前20日成交额1%事前预算及部分成交。

## 选择规则与复核

先生成2023–2024连续验证账本。每年从相邻年末实际净值计算收益（2023从初始资金），与完全相同起点的指数比较。满足验证期净收益为正、累计超额为正、最大回撤<=25%的候选中，按最差年度超额收益优先、再按总超额收益排序。若无候选满足，保留同一排序并记录验证门槛未满足。

选择结果和完整验证表先落盘，再评估2025–2026。全部最终候选表用于诚实呈现用户这次历史研究要求，不用最终结果冒充之前的验证选择。若预选不达新目标，应明确写出失败；若另有历史复核胜出者，可以列为探索候选，但不得贴上独立验证胜出的标签。

复核：独立现金/持仓账本、未来标签扰动、训练边界、目标仓位因果性；选定策略双倍费用、信号延迟、逐年/半年表现，含分红基准可获得性。所有实验输入、源码、协议和结果保存身份及哈希。结果确定后更新平台、报告、Beamer与GitHub，保留v2.0.0。
